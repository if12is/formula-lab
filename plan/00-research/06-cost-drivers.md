# كل العناصر اللي بتتحكم في السعر (Cost Model)

الهدف: التكلفة الحقيقية للعبوة الواحدة عند باب المصنع ثم سعر المستهلك، وكل بند بمصدره وتاريخه.

## 1) تكلفة الخامة الواصلة (Landed Cost) لكل خامة/فارغ
```
Landed/kg = [ (سعر المورد × كمية) × FX
            + شحن دولي + تأمين
            + جمارك (% من القيمة الجمركية حسب HS)
            + تخليص + أرضيات + نقل داخلي
            + رسوم فحص/إفراج (EDA للخامات التجميلية)
            + تكلفة تمويل (أيام السداد × سعر الفايدة)
            − VAT مدخلات قابلة للخصم ] / الكمية المستلمة الصالحة
```
- كل بند ليه مصدر ومستند (فاتورة، بوليصة، إذن إفراج).
- الكمية الصالحة = المستلمة − المرفوض في الفحص.
- محليًا: سعر المورد + نقل + VAT غير قابل للخصم (لو فيه) + تمويل.
- **شرائح السعر وحد أدنى للطلب (MOQ):** السعر بيتحسب من الشريحة اللي الكمية الفعلية بتقع فيها.

## 2) خامات التركيبة
`material_cost/kg = Σ (pᵢ/100 × landedᵢ)` ⇒ ثم ÷ (1 − فاقد التصنيع)

## 3) التغليف (Packaging BOM) لكل SKU
| البند | الوحدة | ملاحظات |
| --- | --- | --- |
| عبوة / فارغ (زجاجة، جركن، برطمان، أنبوبة، كيس) | قطعة | + نسبة الكسر/المرفوض |
| غطاء / بلف / بمب / تريجر / سبراي / dip tube | قطعة | |
| سدادة / ختم حراري (induction seal) | قطعة | |
| ليبل أمامي/خلفي أو sleeve | قطعة | تكلفة الطباعة + الأكلشيه موزعة على الكمية |
| علبة فردية (للعطور والكريمات) | قطعة | |
| كرتونة شحن | قطعة | ÷ عدد العبوات في الكرتونة |
| فواصل، شريط لزق، stretch film، بالتة | لكل كرتونة/بالتة | ÷ العبوات |
| حبر تاريخ/تشغيلة | لكل عبوة | |
`packaging_cost/unit = Σ (سعر البند × الكمية لكل وحدة) / (1 − نسبة المرفوض للبند)`

## 4) التعبئة والزيادة القانونية (Overfill)
- ES 2295 "كمية المنتج في العبوات سابقة التعبئة" مطابقة تقنيًا لـ OIML R 87.
- المصنع غالبًا بيعبّي زيادة عشان ميقعش تحت حد العجز المسموح ⇒ **الزيادة دي تكلفة** لازم تتحسب:
  `fill_actual = nominal + overfill` و `product_cost/unit = fill_actual × cost/kg (أو /L بالكثافة)`.
- الحد المسموح للعجز من نص ES 2295 (يتشترى) — مُدخل.

## 5) التحويل (Conversion)
- عمالة: دقائق عمل لكل دفعة/عبوة × أجر الدقيقة المحمّل.
- طاقة: kWh لكل دفعة (خلط، تسخين للكريمات والصابون) × سعر.
- مياه منزوعة الأملاح: لتر × تكلفة اللتر (من محطة المعالجة).
- تكاليف غير مباشرة (إيجار، إهلاك معدات، إدارة) موزعة بمفتاح ثابت (لكل كيلو أو لكل ساعة خط) — المفتاح يتحدد مرة ويتسجل.

## 6) الجودة والتنظيم
- اختبارات لكل دفعة (pH، كثافة، ميكروبيولوجي للتجميل) ÷ عدد العبوات.
- رسوم إخطار EDA والتسجيل وشهادات IFRA موزعة على كمية متوقعة لمدة الإخطار.
- عينات المعمل والاحتفاظ (retention samples).

## 7) الضرايب
- ضريبة القيمة المضافة 14%. من قوانين 2026 (148–155) الصابون والمنظفات المنزلية انتقلت من ضريبة جدول 5% لـ VAT 14% مع خصم ضريبة المدخلات.
- ⚠️ العطور ومستحضرات التجميل كان عليها تاريخيًا ضريبة جدول إضافية؛ **الوضع الحالي لازم يتأكد مع محاسب ضرائب** قبل ما يتبرمج.
- البرنامج يخزن نظام الضريبة لكل عائلة منتج كإعداد مؤرخ (مش ثابت في الكود).

## 8) التوزيع وسلّم السعر (Price Waterfall)
```
تكلفة المصنع للوحدة
+ هامش المصنع        ⇒ سعر بيع المصنع
+ نقل وتوزيع للعميل
+ هامش الموزع/الجملة  ⇒ سعر الجملة
+ هامش التاجر         ⇒ سعر المستهلك قبل الضريبة
+ VAT                 ⇒ سعر المستهلك (المطبوع)
```
- يتحسب في الاتجاهين: من التكلفة للسعر، ومن سعر الرف المستهدف لأقصى تكلفة مسموحة (يغذي المُحسِّن والفئات).
- مرتجعات/هالك سوق % ومصاريف ترويج % كبنود اختيارية.

## 9) الحساسية للعملة
- لكل SKU: نسبة التكلفة المرتبطة بالدولار ⇒ "لو الدولار زاد 10% التكلفة تزيد كام".
