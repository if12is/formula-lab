# خطة منصة التركيبات الدقيقة (Formulation Platform) — من A لـ Z

منصة لمصانع ومعامل المنظفات ومستحضرات التجميل في مصر:
تركيبات + تكلفة + إنتاج + مطابقة مواصفات، بحسابات **deterministic** (نفس المدخلات = نفس الناتج دايمًا)،
مع **Claude Haiku** كمساعد بيستدعي المحرك الحسابي ومايحسبش بنفسه.

## النطاق (قرار صاحب المشروع 2026-11-21)
**Formula Lab مخصص للتركيبات بس: ده صلبه وأساسه.** أي حاجة تجارية أو تشغيلية بتتعمل في Sanad ويتربط بيها بالـ API.

| جوه Formula Lab (الأساس) | في Sanad (عن طريق API) |
| --- | --- |
| التركيبات ونسخها واعتمادها | الموردين والمشتريات وكشوف الحساب |
| المحرك الحسابي الحتمي وكل الحاسبات | المخزون وحركاته والجرد |
| داتا الخامات وشهادات COA ومصادرها | المبيعات والفواتير والعملاء |
| تكلفة التركيبة والعبوة (خامات واصلة + تغليف + تحويل) | الموزعين وأسعار الجملة |
| الفئات (اقتصادي/متوسط/فاخر) والمُحسِّن | تنفيذ الإنتاج على المخزون (صرف واستلام) |
| المطابقة (ES/CosIng/IFRA) والبطاقة | الكاشير والورديات والفروع |
| حلقة المعمل والقياسات | |
| Claude Haiku كمساعد تركيبات | |

- Formula Lab بيبعت لـ Sanad: المنتج التام + تكلفة الوحدة المحسوبة + سعر مقترح + أمر إنتاج معتمد (BOM). Sanad هو اللي بينفّذ على المخزون والبيع.
- مرحلة R (شبكة/بوابة الموردين) **مؤجلة** لحد ما الأساس يخلص.
- مرحلة Q مقصورة على: ورقة الوزن، وأمر الإنتاج المعتمد اللي بيتبعت لـ Sanad، وتتبع الدفعة المرتبط بالتركيبة، ومقارنة التكلفة الفعلية بالمحسوبة. أي مخزن أو حركات مخزون = Sanad.

## المبدأ الحاكم (اقراه قبل أي حاجة)

1. **كل رقم نهائي بيطلع من المحرك الحسابي (Engine)**، مش من الـ AI ومش من تخمين.
2. **كل قيمة داخلة ليها مصدر ودرجة ثقة** (COA > TDS > مواصفة > مرجع عام > تقدير).
3. **قيمة ناقصة = الحساب يقف ويقول ناقص إيه**، ممنوع صفر أو قيمة افتراضية صامتة.
4. **التركيبات الشائعة = قوالب بداية مش حقائق.** أي تركيبة من مكتبة لازم تعدي على المحرك (مجموع 100%، مادة فعالة، حدود، تكلفة) وتتعلّم "غير متحقق منها" لحد ما تتجرب في معمل.
5. **الفئات (اقتصادي / متوسط / فاخر) = مسألة تحسين رياضي (Linear Programming)** بقيود مختلفة لكل فئة، والحل deterministic: نفس القيود والأسعار = نفس التركيبة الأرخص.
6. **اللي مش ممكن يتحسب بمعادلة (لزوجة، ثبات، رغوة)** بيتقاس في المعمل ويتخزن، والبرنامج بيعمل interpolation على القياسات الحقيقية بتاعتك، مش تنبؤ.

## الستاك المقترح (متوافق مع خبرتك)

- **Engine:** TypeScript package مستقل (`@fp/engine`) + `decimal.js` — يشتغل في المتصفح وElectron والموبايل والسيرفر بنفس الكود.
- **Optimizer:** HiGHS (`highs` npm, WASM) — solver خطي deterministic.
- **Backend:** Laravel 12 + PostgreSQL (الداتا المرجعية، الموردين، المزامنة، الـ AI proxy).
- **Frontend:** Vue 3 + Inertia + **Taif Kit** (`if12is/taif-kit`: tokens، app shell، 184 component، templates) — ممنوع نبني UI من الصفر.
- **POS والتجارة:** **Sanad** (`wasef201/sanad`) هو مصدر الحقيقة للموردين والمشتريات والمخزون والمبيعات والعملاء والموزعين؛ Formula Lab بيكلمه بالـ API.
- **Offline:** SQLite محلي + مزامنة (PowerSync أو outbox/cursor).
- **AI:** Claude Haiku عبر الـ API من السيرفر فقط (المفتاح ما يوصلش للعميل).
- **Tests:** Vitest (engine) + Pest (Laravel) + Playwright (e2e).
