# قوالب جمع الداتا
- `materials.csv` — الدرجات التجارية وخواصها (صف لكل درجة من كل مورد)
- `coa.csv` — قيم شهادات التحليل (صف لكل خاصية)
- `prices.csv` — أسعار مؤرخة (ممنوع سعر من غير تاريخ)
- `formulas.csv` — تركيبات حقيقية من المصانع (مجهّلة)
- `lab_results.csv` — قياسات المعمل
كلها UTF-8 with BOM عشان Excel يفتح العربي صح. الأعمدة الفاضية = غير معروف (مش صفر).

## قوالب المشتريات والتكلفة
- `packaging.csv` — الفوارغ والأغطية والبمبات والليبلات والعلب والكراتين (بأسعار وشرائح وMOQ)
- `sku_packaging_bom.csv` — قائمة التغليف لكل SKU
- `landed_cost.csv` — فواتير الشراء وبنود الشحن والجمارك والتخليص
- `cost_centers.csv` — أسعار العمالة والكهرباء والمياه
- `skus.csv` — كل SKU: الحجم، الكثافة، الزيادة، الكرتونة، الهوامش، سعر الرف المستهدف
- `tax_matrix.csv` — نظام الضريبة لكل عائلة منتج (يتأكد من محاسب)
